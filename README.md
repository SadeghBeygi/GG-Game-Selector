# NEXUS // GG — PS5 Game Library System

A cyberpunk-themed React web app for **Ghanat Gameroom** (گیم روم قنات) that lets customers browse, filter, and prioritize PS5 games they want installed on their console.

## ✨ Features

- **Game Grid** — Responsive grid (2–5 columns) with procedural cover art and Metacritic ratings
- **Smart Filters** — Search by title, filter by genre, sort A-Z / Z-A / Year / Rating
- **Priority List** — Select games, then drag-and-drop to rank your Top 5
- **Top 5 Highlight** — The first five slots in the priority list are visually emphasized with a divider
- **RTL Support** — Full Farsi (فارسی) language support with proper right-to-left layout
- **Contact Popup** — Business info with Telegram, Bale, and Instagram links
- **Glass-morphism UI** — Dark cyberpunk aesthetic with Orbitron + Vazirmatn typography
- **Fully Responsive** — Optimized for mobile (375px+) and desktop

---

## 🛠 Tech Stack

- **React 18** (Functional Components + Hooks)
- **Tailwind CSS** (utility-first styling)
- **Lucide React** (icon library)
- **Vazirmatn** font for Persian / Arabic text
- **Orbitron** font for display headings
- **React Portal** for modal rendering

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ and npm / yarn

### Installation

```bash
# Clone the repo
git clone https://github.com/your-username/nexus-gg.git
cd nexus-gg

# Install dependencies
npm install

# Start the dev server
npm run dev
